# 📊 Customer Churn Analysis — 100K Customers

> **Data Analyst Portfolio Project | Excel + Power BI**

An end-to-end customer churn analysis project using a **100,000-customer dataset**. The project focuses on understanding churn behavior across customer segments, subscription characteristics, tenure, payment methods, internet services, and time.

---

## 🎯 Project Objective

Customer churn is a key business challenge for subscription-based businesses. The objective of this project is to analyze customer churn patterns and build an interactive dashboard that helps stakeholders quickly identify churn trends and high-risk customer segments.

### Key Questions

- What is the overall customer churn rate?
- How does churn vary by contract type?
- Which subscription plans have higher churn?
- Does customer tenure show different churn patterns?
- How does churn vary by payment method and internet service?
- How has churn rate changed over time?

## 🔎 Key Findings

### Overall Churn
The dataset contains **100,000 customers**, of which **20,215 customers are churned**, resulting in an overall churn rate of **20.22%**.

### Contract Type
Churn is relatively consistent across contract types:

- Monthly: **6,743 churned customers**
- Two-Year: **6,771 churned customers**
- Yearly: **6,701 churned customers**

### Subscription Plan
Churn is also closely distributed across plans:

- Basic: **6,723**
- Premium: **6,817**
- Standard: **6,675**

### Payment Method
UPI has the highest number of churned customers at **5,202**, while Net Banking has the lowest at **4,989**.

### Internet Service
Churned customers by internet service:

- Fiber: **6,793**
- DSL: **6,728**
- 5G: **6,694**

### Support Calls
The **8–10 support-call** segment contains the largest number of customers and **5,386 churned customers**.

### Tenure
The customer base is distributed across six tenure groups from **1–10 months** through **51–60 months**, allowing churn behavior to be compared across customer lifecycle stages.

### Time Trend
The dashboard tracks churn rate by **year and quarter**, making it possible to monitor changes in churn over time.
